# رالی‌یار؛ اصلاح فرم و یکپارچگی برند

پاسخ گزارش‌شده نشان‌دهنده خطای اعتبارسنجی Zod بود؛ پاسخ قدیمی نام فیلد و مقدار ارسالی را مشخص نمی‌کرد، بنابراین فیلد دقیق همان درخواست از روی آن قابل تعیین نیست.

اصلاحات مشترک فرم‌ها:
- نام و متن trim می‌شوند؛ خطاهای طول نام/آدرس فیلد مشخص دارند و محدودیت مرورگر باشگاه با سرور همسان شد.
- مختصات، مبالغ و اعداد از مسیر مشترک ارقام فارسی/عربی، جداکننده هزارگان و اعشار فارسی می‌گذرند؛ مقدار خالی به صفر تبدیل نمی‌شود.
- نشانی کوتاه شهر، باشگاه و رویداد به حروف کوچک و فاصله به خط تیره تبدیل می‌شود. نشانی غیرلاتین پیام واضح دارد.
- انتخاب نامعتبر، کلید تکراری و وابستگی پیدا‌نشده پیام قابل اقدام دارند؛ هیچ اعتبارسنجی حساس دیتابیس حذف نشده است.

نام، لوگو، شعار، footer، hero، metadata، OG، favicon، ورود و حساب و مدیریت به رالی‌یار یکپارچه شدند. تصاویر کاربر بدون بازسازی استفاده شده‌اند. DESIGN.md مرجع برند، توکن، حالات، لحن و حرکت است.

۲۸ تست واحد/SQL/قرارداد موفق؛ ۲۴ تست مرورگر روی دسکتاپ/موبایل موفق، از جمله ثبت و ماندگاری باشگاه و خطای نام از سمت سرور. تصاویر صفحه اصلی هر دو اندازه بررسی شد؛ overflow افقی مشاهده نشد. build و lint موفق. تست‌های PostgreSQL آزمون‌اند؛ باشگاه نمایشی روی production ایجاد نشده است.

برای این تغییر migration تازه یا دست‌کاری سیاست رزرو، پرداخت و رتبه‌بندی لازم نشد. آدرس‌ها و دامنه سایت حفظ شدند.
