# تخفیف و معرفی باشگاه

- شمارش معکوس درخواست و پرداخت با ارقام فارسی، زمان پایه سرور، هشدار پنج دقیقه پایانی و تازه‌سازی در پایان مهلت.
- معافیت با دسترسی مدیریت و دلیل اجباری؛ قابل اعمال روی مانده پس از تخفیف. وضعیت تسویه از پرداخت بانکی متمایز است.
- کد درصدی یا مبلغ ثابت، انقضا، فعال/غیرفعال، سقف کل و یک استفاده برای هر حساب؛ بدون ترکیب چند کد. لغو سهم، ظرفیت کد مصرف‌شده را آزاد نمی‌کند.
- کنترل نگه‌داشت واقعی، انقضا، قفل سهم، پرداخت در حال بررسی و ظرفیت استفاده در RPC تراکنشی. تغییر قیمت فقط برای سهم رزروشده و پیش از پرداخت انجام می‌شود. اصل مبالغ و تغییرات برای حسابرسی حفظ می‌شوند.
- نوع ورزش هر زمین و SVGهای پدل، تنیس، تنیس ساحلی، اسکواش، بدمینتون و زمین عمومی؛ آیکون راکت/توپ در انتخاب تجهیزات.
- عکس واقعی ثبت‌شده، آدرس و نقشه مختصات باشگاه؛ تصویر Open Graph و داده ساختاریافته SportsActivityLocation. بدون مختصات صرفاً جست‌وجوی آدرس ارائه می‌شود.

## اعتبارسنجی

تست‌های SQL شامل جلوگیری از معافیت کاربر عادی، الزام نگه‌داشت، عدم ایجاد رسید بانکی برای سهم رایگان، دریافت دقیق مانده تخفیف از درگاه، معافیت مانده توسط ادمین، حفظ مبلغ اصلی، RLS کدها، انقضا، سقف مصرف، تکرار امن درخواست و مسدودکردن تغییر مبلغ هنگام پرداخت هستند.

تست مرورگر مسیر واقعی ورود بازیکن، درخواست، کاهش شمارنده، تأیید نگه‌داشت توسط مدیر، ایجاد کد درصدی، استفاده بازیکن، معافیت مانده و نمایش تسویه بدون پرداخت را در دسکتاپ و موبایل اجرا می‌کند. این تست‌ها دیتابیس محلی با تمام migrationهای واقعی دارند؛ هیچ رزرو یا پرداخت تولیدی برای تست ساخته نشده است.

SQL در `supabase/migrations/20261022143309_booking_benefits.sql` است. متغیر محیطی جدید لازم نیست. راهنمای مدیریت در README آمده است.
