# الگوهای پیامکی مچ شو برای OnlinePayamak

این نام‌ها در کد ثابت‌اند. هر الگو را با **همین نام لاتین و همین متن** در پنل بسازید و پس از تأیید فعال کنید. `loginotp` موجود را دوباره نسازید؛ اگر قبلاً تأیید شده می‌تواند با متن فعلی دارای `%token` باقی بماند.

## قرارداد API

طبق متن مستندات رسمی https://api.onlinepayamak.com که مالک پروژه در این گفتگو ارائه کرد، `POST /v1/{API-KEY}/verify/lookup.json` برای OTP و اطلاع‌رسانی‌های تکراری است. فیلدهای اجباری: `receptor`، `template` و `token`. `token` حداکثر ۱۰۰ نویسه است و فاصله، خط جدید و زیرخط ندارد. تمام قالب‌های زیر فقط همین یک متغیر را دارند؛ `token2/3/10/20`، متن آزاد و خط اختصاصی در درخواست استفاده نمی‌شوند. نام کسب‌وکار در تمام متن‌ها آمده است.

برای OTP مقدار `%token` همان کد یک‌بارمصرف است. در اعلان‌ها مقدار آن شناسهٔ عددی اعلان است؛ کد ورود یا شمارهٔ رزرو نیست. متن دلخواه مدیر، علت رد، نام طولانی و لینک متغیر داخل توکن قرار نمی‌گیرد؛ جزئیات کامل در حساب کاربر باقی می‌ماند. لینک‌ها ثابت و متعلق به match-sho.com هستند. پنل باید هر متن را جداگانه تأیید کند؛ تغییر متن مصوب ممکن است بررسی مجدد بخواهد.

این محیط نتوانست خود صفحهٔ مستندات را باز کند؛ قرارداد بالا از متن مستندات ارسال‌شده توسط مالک بررسی شده و با مسیر OTP موجود تطبیق داده شده است. تأیید یا ارسال واقعی هیچ الگوی جدیدی ادعا نمی‌شود.

## متن‌های آمادهٔ ثبت

### loginotp

```text
مچ شو
کد تأیید شما: %token
این کد را در اختیار دیگران قرار ندهید.
```

### bookingrequest

```text
مچ شو
درخواست رزرو شما ثبت شد. وضعیت پرداخت و تأیید باشگاه را در حساب خود دنبال کنید.
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

### bookinghold

```text
مچ شو
باشگاه سانس شما را موقتاً نگه داشته است. مهلت پرداخت را در حساب خود بررسی کنید.
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

### bookingpaid

```text
مچ شو
پرداخت شما تأیید شد؛ رزرو در انتظار تأیید نهایی باشگاه است.
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

### bookingconfirmed

```text
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

```text
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

### bookingexpired

```text
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

### bookingquote

```text
شناسه اعلان: %token
https://match-sho.com/account/bookings
```

### playerjoined

```text

شناسه اعلان: %token

```


### refundrequested

```text
https://match-sho.com/account/payments
```

### refundcompleted

```text
شناسه اعلان: %token
https://match-sho.com/admin/operations?tab=queue
```

### adminreceipt

```text
مچ شو - مدیر

شناسه اعلان: %token
https://match-sho.com/admin/operations?tab=receipts
```

### adminreschedule

```text
مچ شو - مدیر
پاسخ کاربر به پیشنهاد زمان جایگزین ثبت شد. نتیجه را در صف مدیریت بررسی کنید.
شناسه اعلان: %token
https://match-sho.com/admin/operations?tab=queue
```

## فعال‌سازی روی سرور

پس از تأیید **همهٔ قالب‌های اعلان**، در env برنامه (روی سرور: `/opt/matchsho/shared/app.env`) تنظیم کنید:

```dotenv
ONLINEPAYAMAK_OTP_TEMPLATE=loginotp
ONLINEPAYAMAK_NOTIFICATION_SMS_ENABLED=true
```

`ONLINEPAYAMAK_API_KEY` فقط سمت سرور لازم است. `ONLINEPAYAMAK_SENDER` برای ارسال با الگو لازم نیست. OTP به پرچم اعلان‌ها وابسته نیست؛ تا پیش از تأیید قالب‌ها، پرچم اعلان‌ها `false` بماند تا تلاش‌های صف برای قالب تأییدنشده مصرف نشوند. پس از انتشار کد جدید و تغییر env، سرویس `web` را recreate کنید. scheduler باید طبق راهنمای استقرار هر دقیقه `/api/jobs` را با کلید سروری فراخوانی کند.

شمارهٔ کاربر باید در Auth تأییدشده باشد. `ADMIN_NOTIFICATION_PHONES` مسیر جایگزین شمارهٔ مدیر اصلی است. شماره، API key و OTP را در Git یا لاگ عمومی ننویسید.

اعلان بدون نگاشت شناخته‌شده با `SMS_TEMPLATE_UNMAPPED` رد می‌شود و به متن آزاد تبدیل نمی‌شود. پذیرش API معادل تحویل قطعی نیست؛ شناسهٔ `messageid` برای پیگیری ذخیره می‌شود. متد الگو در مستندات ارائه‌شده پارامتر `localid` ندارد؛ شناسهٔ اعلان در `token` کلید جلوگیری از ارسال تکراری در سرویس نیست و در تلاش مجدد ممکن است پیام تکرار شود.

خطاهای مستند متداول: `418` اعتبار ناکافی، `422` نویسه نامعتبر، `424` قالب پیدا نشده یا تأیید نشده، `426` متد غیرفعال، `431` ساختار کد نادرست، `432` نبودن `%token` در متن. وضعیت عددی سرویس در لاگ Hook و نتیجهٔ رد اعلان ثبت می‌شود؛ نام و متن قالب را در پنل بررسی کنید.
